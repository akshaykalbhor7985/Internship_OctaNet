# Internship_OctaNet

A pair of front-end internship exercises demonstrating responsive layout and simple interactivity.

- Task1: A responsive, Netflix-style landing page (hero, feature sections, embedded videos, FAQ, footer).
- Task2: A minimal To‑Do list web app implemented with jQuery (add, complete, delete tasks).

## Stack
- Languages: HTML, CSS (primary)
- Libraries: jQuery (CDN) and Font Awesome (CDN) used in Task2
- No build tools or backend required — static assets only.
